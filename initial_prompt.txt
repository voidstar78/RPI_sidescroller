I want a C or C++ program, or something that can be compiled using gcc (or c++ or whatever compiler is available on RPi5 and Raspbery Pi OS).
I would accept a Python script if it capable of doing this program, but would prefer a cross-platform compatible program.

The program is to be a side scroller program, that scrolls a given text across the screen.  I want this scrolled text to be in a regular GUI Window.  I want an easy way to set the scroll text (either as a command line or an input file; since the text to be scrolled could be long, like maybe even 1000 characters, I'd prefer the input text to be an external file that is in the same folder as the program executable).   I would like a way to adjust the font of the scrolled text (by name and size), with some reasonable system default (like Courier New, 72 point).  I want the scrolled text to be visible from several feet away, so several inches in height, but not excessive.  Ideally the font size would scale to the vertical size of the GUI window, so users can adjust the scroll dynamically as needed based on the situation.   I'd like to be able to use arrow keys to adjust the speed of the horizontally scrolled text.   To clarify what I mean by scrolled text, I don't mean vertically scrolled like a regular screen or printer text.  In this program, I mean horizontally scrolled, such that only a portion of the text is visible at a time.  For example, if the entire text is 1000 characters, only 30 characters at a time might be visible (due to the current font size and size of the GUI window doing the scrolling).   A normal default of scroll would be about 4 characters per second.   When the entire text has been scrolled, there is a white space border at the beginning and end of the scrolled text, but the scrolling repeats again indefinitely (until the program GUI window is closed).

Because GUI Window code is generally not cross-platform, I'd like to use whatever is the most broadly supported GUI library code.
This is why Python might be an acceptable alternative, since C or C++ generally does not include a GUI Window library.
